#  Animated Services Section

A modern, responsive, and interactive services section built with **React and Tailwind CSS**, featuring smooth animations, image transitions, and a light/dark theme switcher.

This project focuses on creating an engaging user experience through clean UI design, subtle motion effects, and reusable React components. It is designed to be integrated into modern business websites, agency websites, and developer portfolios.

##  Live Demo

**Live Preview:** (https://animated-services-section.vercel.app/)

##  Features

- **Modern UI Design** — A clean and visually engaging services layout.
- **Smooth Animations** — GSAP-powered scroll effects, hover interactions, and animated elements.
- **Interactive Image Slider** — Smooth image transitions powered by Framer Motion.
- **Light & Dark Themes** — Switch between light and dark modes.
- **Theme Persistence** — Remembers the selected theme using local storage.
- **Responsive Layout** — Designed to adapt to different screen sizes.
- **Interactive Service Cards** — Hover effects and animated visual elements.
- **Reusable React Component** — Easy to customize and integrate into other projects.

##  Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm installed on your computer
- Git installed on your computer

### 1. Clone the Repository

```bash
git clone https://github.com/Tooba-Saleem22/animated-services-section.git
```

### 2. Navigate to the Project Folder

```bash
cd animated-services-section
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the project.

### 5. Create a Production Build

```bash
npm run build
```

##  Customization

You can personalize the section to match your website's design:

- Update service titles and descriptions in `PreProduction.jsx`.
- Replace the images inside `public/images/`.
- Customize colors, typography, spacing, and layout using Tailwind CSS and `index.css`.
- Adjust GSAP and Framer Motion animations to create your preferred visual effects.
- Modify the theme toggle and its styling to match your brand.

**Tip:** Keep image filenames and their paths consistent when replacing project images.
